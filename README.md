# Projeto Botão - Kotlin

Autor: Mateus Fernandes Mano

Um projeto simples, desenvolvido em Kotlin pela plataforma Android Studio. O projeto simula um contador simples, com três botões - um para incrementar, outro para decrementar e um botão de reset — exibindo o valor atual na tela, atualizado imediatamente a cada toque.

## Objetivo

O projeto teve como objetivo principal, praticar conceitos básicos do desenvolvimento de aplicativos usando Kotlin, utilizando a criação de interface, interação com botões e gerenciamento de valores que serão exibidos em tela.

O aplicativo desenvolvido tem como funcionalidade principal, incrementar e decrementar o valor do contador, mas como desafio proposto pelo professor, foi adicionado as funções de quando o contador estiver em 0, ele não diminuir e foi adicionado um botão de reset, que, instantaneamente, leva o valor do contador para o 0.
